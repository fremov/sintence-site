Политика конфиденциальности

Последнее обновление: 2026-09-30

Кто мы

Sintence разрабатывает и поддерживает независимый разработчик («мы»). Связь: sintence.official@gmail.com.

Какие данные мы обрабатываем

1. Данные Riot Games API о матчах и игроках

PUUID, Riot ID, ранг, мастери и данные матчей из Riot Games API. Хранятся на сервере Sintence для статистики и кеша ответов API.

2. Пользователи приложения

  • Случайный токен установки. Сервер хранит только его хеш.
  • Ваш Riot ID из клиента игры.
  • Версия приложения и время последней активности.

IP-адреса в базе не хранятся. Журналы веб-сервера ротируются по объёму и не используются для идентификации.

3. На вашем компьютере

Приложение хранит журнал работы и данные встроенного браузера WebView2 в %LOCALAPPDATA%\Sintence. Токен установки — в диспетчере учётных данных Windows.

Зачем

Только для работы функций приложения.

Кому передаём

Никому, данные не продаются. Запросы к Riot Games API идут через сервер Sintence.

Обобщённая статистика сборок не содержит идентификаторов игроков.

Удаление данных

Напишите на sintence.official@gmail.com и укажите свой Riot ID. В течение 30 дней мы удалим и обезличим ваши данные и больше не будем их собирать. Из резервных копий данные уйдут в течение 14 дней. После этого ваш профиль в Sintence показывается как «Профиль закрыт». Мы также исполняем запросы на удаление, которые передаёт Riot Games.

Ваши права

Вы можете запросить по e-mail доступ к своим данным, их исправление или удаление.

Дети

Sintence не предназначен для детей младше 13 лет или младше возраста, установленного законом вашей страны (например, 16 лет в некоторых странах ЕС).

Изменения политики

Мы можем обновлять эту политику. Дата последнего обновления указана в начале страницы.
